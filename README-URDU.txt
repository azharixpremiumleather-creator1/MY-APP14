AZHARIX COLLEGE MANAGEMENT SYSTEM — اردو ہدایات
=================================================

اس ZIP میں یہ فائلیں شامل ہیں:
1. index.html  — ویب سائٹ کا صفحہ
2. style.css   — ڈیزائن اور رنگ
3. script.js   — بٹن، سائن اپ ڈیمو، لاگ اِن ڈیمو اور ڈیش بورڈ
4. README-URDU.txt — یہ ہدایات

اپنے کمپیوٹر پر پریویو:
1. ZIP پر Right-click کریں اور Extract All کریں۔
2. AZHARIX_College_Website فولڈر کھولیں۔
3. index.html پر ڈبل کلک کریں۔ بہتر ہے تمام فائلیں اسی فولڈر میں رہنے دیں۔

GitHub پر اپلوڈ:
1. اپنی GitHub repository کھولیں۔
2. اگر اس میں پرانی/غلط فائلیں ہیں تو انہیں دیکھ کر درست کریں؛ صرف ZIP اپلوڈ کرکے نہ چھوڑیں۔
3. Add file > Upload files پر کلک کریں۔
4. اس فولڈر کے اندر کی چاروں فائلیں منتخب کریں: index.html, style.css, script.js, README-URDU.txt
   (فائلیں فولڈر کے اندر سے اپلوڈ کریں، ZIP فائل نہیں)
5. Commit changes کریں۔
6. Settings > Pages > Build and deployment میں Deploy from a branch منتخب کریں۔
7. Branch: main اور Folder: /(root) منتخب کرکے Save کریں۔
8. ایک سے چند منٹ بعد اسی Pages صفحے پر دکھائے گئے Visit site لنک کو کھولیں۔
9. index.html لازماً repository کی جڑ (root) میں ہو، کسی اضافی اندرونی فولڈر میں نہیں۔

ضروری حقیقت:
یہ ایک فرنٹ اینڈ ڈیزائن/انٹرایکٹو ڈیمو ہے۔ OTP کے لیے 123456 صرف پریویو کو دکھانے کا فرضی کوڈ ہے؛ کوئی ای میل نہیں بھیجی جاتی۔
لاگ اِن، اکاؤنٹس، فیس، حاضری اور رزلٹ کا ڈیٹا سرور یا ڈیٹا بیس میں محفوظ نہیں ہوتا۔
حقیقی کالج استعمال کے لیے محفوظ بیک اینڈ، ڈیٹا بیس، ای میل OTP، تصدیق شدہ کالج IDs، اور سکیورٹی کی الگ تیاری درکار ہے۔
کسی اصلی طالب علم کا شناختی نمبر، پاس ورڈ یا نجی ڈیٹا اس ڈیمو میں نہ ڈالیں۔
